# ColorLab — 24 色卡照片校色

这是独立的、无需服务器的浏览器照片校色工具，入口为 [网站 /colorchecker/](https://ybyllc.github.io/colorchecker/)。

## 使用

1. 上传同一台相机拍摄的 ColorChecker Classic 风格 24 色卡照片（6 列 × 4 行）；
2. 上传希望校正的 JPG、PNG 或 WebP 普通照片；
3. 检查自动框选的黑色外框。如不准确，依次点击外框左上、右上、右下、左下四角；
4. 保持「自动识别」色卡方向（若误判可以手动切换到顶部黑→白或顶部棕色）；
5. 点击「开始校色」，调整校正强度，下载 JPG/PNG。

## 实现原理

- 从 24 个色块中心采样中位数，尽量避开黑色分隔线；
- 灰阶估算 R/G 与 B/G 线性白平衡增益；
- 根据中间灰估算用于拟合的全局亮度归一化；
- 通过正则化加权最小二乘求解保中性轴的 3×3 CCM；
- 在线性 sRGB 近似空间处理目标图像，在本地预览和导出；
- 页面中可查看 AWB、CCM 和色卡平均 CIE76 色差估算值。

## 精度限制

此工具不是 RAW ISP 标定器。处理过的 JPEG 可能经过 AWB、CCM、Gamma、HDR、局部色调映射和压缩，不能期望完全恢复出标准色。标定照片与目标照片应来自同一相机、相近光照及相同色彩处理配置。不同批次或厂商 24 色卡可能不匹配内置 ColorChecker Classic 参考值。默认不修改整体曝光；勾选曝光校正需谨慎。

参考 sRGB 色块表使用常见 ColorChecker Classic 24 色近似值，例如 dark skin [115,82,68]、Neutral 8 [200,200,200]、black [52,52,52]。参考：Sensors 2020, 20(19), 5658 的色块 RGB 表、X-Rite 相关资料。平均色差采用 ΔE76，**不是** ΔE00。

图像始终在浏览器内本地处理，页面没有图片上传 API、跟踪或第三方脚本。为了控制浏览器内存，下载时长边不超过 5200 像素、最大约 1800 万像素。
