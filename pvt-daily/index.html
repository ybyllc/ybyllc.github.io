测试规则：尽可能贴近研究

  1. 每天选固定时间，最好起床后相近的时间间隔进行，避免刚醒来的睡眠惯性。
  2. 坐在安静的房间，手机放稳（或电脑键盘），尽量同一设备、亮度和姿势。
  3. 测试开始后会有3秒倒计时；随机等待2–10秒，数字出现马上点击灰色区域或按空格。
  4. 不要抢按、连按或预测刺激。如果误触会记录为提前反应。
  5. 正式测试可选2、5、10分钟；1分钟仅为体验。刺激出现后30秒未反应视为超时。
  6. 每次结束自动生成详细单次报告，历史记录可重新打开。不同测试时长应分开对照。
  7. 测试中切后台、切标签页或失去窗口焦点，会停止并丢弃这次测试，防止被打断的数据混入历史。
请勿故意熬夜或减少睡眠来验证效果。本工具不能估计智商，也不能诊断睡眠疾病、判断青春期是否造成永久脑损伤。

统计口径

有效反应（RT）

刺激出现到点击／按键的毫秒数，≥100ms；未回应30秒按30000ms记入一次超时。

迟缓（Lapses）

有效反应时间 ≥500ms 的次数，越少通常表示更稳定的持续注意力。

误反应（False starts）

没有刺激时抢按，或刺激后不足100ms作答；不纳入正常反应均值。

平均倒数反应速度

所有有效RT以秒为单位计算 1/RT 后求平均，这是研究常用指标之一。

KSS困倦分

在测试前按最近几分钟的感觉打1–9分；1表示极清醒，5表示不困不醒，9表示困到必须努力保持清醒。

为什么说它不是“实验室同精度”？

标准实验常使用校准过的精密刺激和反应设备，控制光照、时间、休息和药物等因素。这个网页使用浏览器高精度计时 API 和绘制前回调估算刺激开始时间，但无法知道屏幕像素真正亮起、或触摸硬件真正检测到手指的时刻。因此适合记录同一设备上的长期变化，不适合与论文里的绝对阈值直接比较，更不能从某次成绩推断脑部损伤。
