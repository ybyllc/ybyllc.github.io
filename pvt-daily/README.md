# PVT Daily — 睡眠与注意力实验室

线上地址：https://ybyllc.github.io/pvt-daily/

## v1.2 功能

- 2分钟短测、5分钟中测、10分钟正式PVT范式，每次结束显示单次报告。
- 1分钟体验模式也出报告，但不写入正式历史。
- 单次报告含平均/中位反应时间、≥500ms迟缓次数、误反应、反应分布及相同时长个人历史对照。
- 在「历史数据」可重新打开报告；单次报告支持导出HTML。
- 趋势和睡眠分组仅按相同测试时长比较，不混合2/5/10分钟结果。
- 老版10分钟记录沿用浏览器现有的localStorage，可继续查看。
- 支持CSV/JSON导出与JSON导入。请定期手动备份。

## 使用建议

- 建议日常固定使用2分钟或者5分钟，周期性做10分钟标准版时要单独比较。
- 尽量使用同一设备、相同测试时间与操作方式。
- 不要刻意熬夜做试验。
- 浏览器/触屏反应计时未经硬件校准，不是临床设备，不能估计智商或永久脑损伤。

## 部署

此目录位于 `ybyllc/ybyllc.github.io` 的 `main` 分支，以GitHub Pages独立路径部署，不改变主站首页。PWA文件：`manifest.webmanifest`、`icon.svg`、`sw.js`。

发布更新后若仍显示旧版本，请刷新页面；已经安装到桌面的用户可能需要关闭再打开，确保离线缓存完成更新。
